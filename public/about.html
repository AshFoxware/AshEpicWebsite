How was this page constructed

This page was constructed using Vanilla NodeJS, its a very light site so it only uses a little tiny bit of client JS, with the bulk of dynamic elements being CSS.

The wave was done by animating line segments within an SVG then filling below, with the opacity varying between layers. initially this was done through the CSS layer but this would cause it to fail on Apple devices.

the source is available on my github for anyone who wishes to learn from it.
